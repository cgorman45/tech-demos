# Agent instructions

This is the sticky Tech Demos monorepo.

- One app per pick under `apps/<kebab-slug>/` only.
- - Never create a new GitHub repository.
  - - Use Bun; each app must be self-contained (`bun install && bun run dev`).
    - - Before building, follow `skills/project-planning/` and write `apps/<slug>/PLAN.md`.
      - - PRs must attach BOTH at least one screenshot AND at least one video of the running app.
        - - Do not touch other apps or delete `tracking/` history.
